# Project Setup Guide

This guide will help you set up and run the full project, including the backend, frontend, and browser extension.

---

## Step 1: Clone the Repository

```bash
git clone https://github.com/G10RG131/SofMId.git
```
---

## Step 2: Start the Backend

```bash
cd backend
npm install
npm run dev
```

---

## Step 3: Start the Frontend

Open a **new terminal** and run:

```bash
cd frontend
npm install
npm run dev
```

---

## Step 4: Load the Extension in Your Browser

1. Open your browser and go to the Extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. Enable **Developer Mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select the `extension` folder from the project directory.

---

## ✅ All Set!

- Backend is running.
- Frontend is running.
- Extension is installed.

You're now ready to use the full application!
